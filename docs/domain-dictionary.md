# Domain Dictionary: Hachi

> 最終更新: 2026-09-17

## 音声会話

| 用語 | 定義 | 英語名 / 別名 |
|------|------|--------------|
| 会話 | トークボタンから終了までのひとつづき。WebSocket セッション 1 本と 1 対 1 で対応し、料金の計上単位でもある | `Conversation` / session |
| セッション状態 | 会話が接続中・待受中・終了のどれにいるか。画面はこれだけを見て見た目を決める | `Conversation.State` (CONNECTING / LISTENING / ENDED) |
| 字幕 | 会話中に画面へ流れる文字起こし。ユーザー側とモデル側の両方を含み、断片で届く | caption / transcription |
| 送信ゲート | スピーカーが鳴っている間マイクの音を捨てる仕組み。この端末にエコーキャンセラがないことへの対策 | `SpeakerStream.busy()` / half-duplex gate |
| 鳴り終わり時刻 | 渡した音声が鳴り終わる実時刻の見積もり。AudioTrack の内部位置は割り込みで壊れるため自前で持つ | — |
| 余白 | 鳴り終わってからゲートを開けるまでの 600 ms。部屋の残響と AudioTrack のバッファ遅延の両方を吸う | tail |
| 黙らせる | 再生中の返答だけを捨てて、会話は続けること。喋りかぶせができない代償として画面タップに割り当ててある | `Conversation.hush()` |
| 割り込み | ユーザーが返答に被せたとサーバーが判断した通知。届いたら再生待ちの音声を全部落とす | `interrupted` / barge-in |
| 道具 | モデルが会話中に呼び出せる関数。宣言（JSON）と実行を 1 ファイルに置き、レジストリ経由でのみ会話から見える | tool / function calling |
| 無音タイムアウト | どちらも喋らないまま会話を閉じるまでの秒数。どちらかの発話が届くたびに数え直す | `silenceTimeout` |

## 天気

| 用語 | 定義 | 英語名 / 別名 |
|------|------|--------------|
| 場所 | 天気を引く 1 地点。表示名と緯度経度を持ち、選ばれるまでは天気そのものが出ない | `Place` |
| 予報 | 現在の気温・天気コード・昼夜と、3 日分の最高／最低／天気コード／降水確率 | `Forecast` |
| 天気コード | WMO の天気コード。Open-Meteo がこの形で返す | weather code |
| 雨の列 | 10 分刻みの雨量（mm/h）の並び。先頭が「いま」で 60 分先まで。実測と予測が混ざる | `List<RainPoint>` / rain series |
| いま | 雨の列の先頭。端末の時計ではなくサーバーが刻んだ 10 分刻みの現在を指す | — |
| 雨の要約 | 雨の列を口に出す価値のある事実だけに畳んだもの。降っているか／いつ降り出す／いつ止む／いつ戻る／ピーク | `RainSummary` |
| 戻り | 止んだあと 1 時間以内にまた降り出すこと。「10 分で止む」だけ言うと晴れた 1 時間に聞こえるので別に持つ | `resumesInMinutes` |
| 情景 | 空を描くために天気コードを畳んだ 7 区分（快晴・晴れ時々曇り・曇り・霧・雨・雪・雷） | `SkyScene` |
| 退色 | 情景ごとに空の色から彩度と明度を引くこと。別のパレットではなく同じパレットを褪せさせるので、時刻が透けて残る | wash |
| 天気の写し | アプリ全体で 1 部だけ持つ天気の現在値。場所・予報・雨の列・直近の取得が失敗したかを含む | `WeatherState` |

## 料金

| 用語 | 定義 | 英語名 / 別名 |
|------|------|--------------|
| 使用報告 | Live API がセッション中に送ってくるトークン数。セッションの累計として扱う | `usageMetadata` |
| 単価表 | モデル別・入出力別・モダリティ別の 100 万トークンあたりドル単価。未知のモデルは高いほうで見る | `Rates` |
| 計上 | 届いた使用報告のうち前回からの増分だけに単価を掛け、日次と月次のドル額に足すこと | `Usage.observe()` |
| 不明分 | 内訳（modality 別）の合計と総数の差。捨てずにテキスト単価で計上する | `OTHER` |
| 思考トークン | 内訳にも総数にも現れない `thoughtsTokenCount`。出力として課金されるので手で出力側に足す | — |
| 日次上限 | 今日の使用額の天井。到達したら会話を始めさせず、会話中に超えたらその場で閉じる。0 は無制限 | `dailyCapUsd` |

## 設定

| 用語 | 定義 | 英語名 / 別名 |
|------|------|--------------|
| 設定 | ユーザーに見える値ぜんぶ。1 つの SharedPreferences に入り、読み書きはこのクラス経由だけ | `Settings` |
| 秘密 | API キーやアクセストークン。Keystore の AES/GCM 鍵で包み `<Base64 IV>:<Base64 暗号文>` で保存する | secret |
| 未設定に倒す | 復号できない秘密を例外にせず空文字として返すこと。起動のたびに落ちるより設定画面で入れ直せるほうがよい | — |
| モデル一覧 | 会話に使える Gemini モデルの候補。ListModels の結果を `bidiGenerateContent` で絞ったもの | `ModelCatalog` |
| 既定一覧 | 取得前・オフライン・失敗時に使う手書きのモデル一覧 | `FALLBACK` |
| 投入 | 5 インチの画面で打つには長すぎる値を、開発機から adb のブロードキャストで書き込むこと。debug ビルドのみ | `DebugSettingsReceiver` |

## 画面

| 用語 | 定義 | 英語名 / 別名 |
|------|------|--------------|
| ページャ | 横スワイプで切り替わるホーム画面。現在は時計・天気・雨雲の 3 枚 | `PagerView` |
| 空 | 全ページの背後に敷く 3 段グラデーション。時刻の色に天気の退色を重ねたもの | `SkyView` |
| 昼のパレット | ある時刻における空の 3 色。キーフレームをチャンネルごとに補間し、1 日は巡って真夜中に戻る | `DayPalette` |
| タイル | Web Mercator の 1 枚。縮尺・x・y で指し、端末密度に合わせず原寸で描く | map tile |
| コマ | ナウキャストの 1 時刻分のタイル群。いまは現在のコマだけを描く | frame |
| 淡色地図 | 地理院タイルの淡色地図。雨雲を重ねる下地 | 地理院タイル / GSI pale |
| ナウキャスト | 気象庁の高解像度降水ナウキャスト。雨雲のタイルの出どころ | 高解像度降水ナウキャスト / hrpns |
